# TADJROUNA.1 — تطبيق ساعة الصلاة للتلفاز والهاتف

هذا مشروع Android جاهز للبناء عبر GitHub Actions دون الحاجة إلى كمبيوتر محلي.

## طريقة الحصول على APK باستعمال الهاتف
1. أنشئ مستودعًا جديدًا في GitHub باسم `TADJROUNA1`.
2. ارفع جميع محتويات هذا المجلد إلى المستودع (وليس ملف ZIP نفسه).
3. افتح تبويب **Actions** في المستودع.
4. اختر **Build TADJROUNA.1 APK** ثم **Run workflow**.
5. بعد انتهاء البناء بنجاح، افتح نتيجة التشغيل وانزل إلى **Artifacts**.
6. حمّل `TADJROUNA1-AndroidTV`، ثم فك ضغطه لتحصل على `app-debug.apk`.
7. انقل APK إلى التلفاز وثبّته بعد السماح بالتثبيت من هذا المصدر.

## ملاحظات
- اسم التطبيق: `TADJROUNA.1`
- الأيقونة: الصورة التي زوّدني بها المستخدم.
- التطبيق يفتح بملء الشاشة وبالوضع الأفقي، ويظهر في مشغّل Android TV.
- وظائف الحساب والواجهة المحلية تعمل من ملف HTML. الخطوط الخارجية والصوت وأي خدمة تعتمد على الإنترنت تحتاج اتصالًا.
- هذه نسخة أولية للتجربة؛ يجب اختبارها على موديل التلفاز الفعلي قبل اعتمادها نهائيًا.
